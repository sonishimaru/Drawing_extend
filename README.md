# Drawing Extend

ドローイングを描くように、立体物を設計するブラウザエディター。
左で図形を描くと、右にリアルタイムで 3D として立ち上がります。
立ち上げ方（形式）は右上で切り替えます。

| 形式 | 内容 |
| --- | --- |
| 吊るす | モビール。糸で吊り、重心で傾き、風で回る |
| 立てる | 彫刻。床に置くと倒れるかを計算して、倒れた姿で止まる。「台座」で固定、スライダーで回転台 |
| 掛ける | レリーフ。壁から少し浮かせて取り付け、板厚と積層の影で見せる |

開発プラン: [docs/PLAN.md](docs/PLAN.md)

## 起動

```sh
cd app
npm install
npm run dev        # http://localhost:5173
```

その他: `npm test`（物理・幾何のテスト）、`npm run build`（`app/dist` に静的ファイル）。

## 使い方

| ツール | キー | 操作 |
| --- | --- | --- |
| 選択 | V | クリック／ドラッグで選択・移動、ハンドルで拡大縮小（Shift 比率固定 / Alt 中心から）、角の外側で回転（Shift 15°）、Alt+ドラッグで複製、⌘/Ctrl+D で複製を繰り返し |
| ダイレクト選択 | A | アンカー・ハンドルを個別に編集、Alt+クリックでコーナー⇔スムーズ |
| ペン | P | クリックで直線、ドラッグで曲線、始点クリックで閉じる、Enter/Esc で終了、端点クリックで続きを描く |
| 曲線 | Shift+~ | クリックした点を滑らかに通る曲線、Alt でコーナー、ダブルクリック/Enter で終了 |
| 直線 / 長方形 / 楕円 / 多角形 | \ / M / L / Y | ドラッグ（Shift 正方形・正円・45°、Alt 中心から、多角形はドラッグ中 ↑↓ で辺の数） |
| 糸 | S | 上の結び目から吊る部品へドラッグ（近くの輪郭に吸着、Shift で鉛直） |
| 手のひら | H / Space | 画面の移動。ホイールでスクロール、⌘/Ctrl+ホイールでズーム、⌘/Ctrl+0 で全体 |

- **塗りあり＝板、塗りなし＝ワイヤー**。触れ合う図形は 1 つの部品として接着され、重なった板は積層されます。
- 素材（木材・金属・石材・コンクリート・石膏など）と板厚・線径は、下のバーで選択中の図形に設定します。何も選ばないときは新規図形の既定値になります。
- 吊るす形式では、糸のない部品は最上点から仮に吊られます。右上の **釣り合わせる** で、描いた角度のまま釣り合う位置へ各糸を移動します。
- **開く…** で Illustrator から書き出した SVG（アートボード 2049px 想定、背景の四角は自動で取り除き背景色に反映）や保存した JSON を開けます。
- 図面はブラウザに自動保存されます。
