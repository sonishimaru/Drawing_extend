# Mobile Editor — 開発プラン

ドローイング（Illustrator で図形をエディットして作る作品）を拡張し、
**図形を描くようにモビールを設計できるブラウザエディター**をつくる。

```
┌──────────────────────────────┬──────────────────────────────┐
│  2D 図形エディター（左）        │  3D リアルタイムプレビュー（右）  │
│  長方形 / 円 / ペン / 曲線      │  素材・重さ・バランスを反映       │
│  選択 / ダイレクト選択          │  吊り下げ → 傾き → 揺れ          │
└──────────────────────────────┴──────────────────────────────┘
```

---

## 1. コンセプト：「描いた絵が、そのまま吊るされる」

左側のキャンバスは **モビールの正面図（立面図）** として扱う。

| 2D で描くもの | 3D での意味 |
| --- | --- |
| 閉じた図形（長方形・円・閉じたパス） | 板状のパーツ（素材 × 厚みで押し出し） |
| 開いたパス（ペン・曲線） | ワイヤー / 腕（棒材。断面径を指定） |
| 吊り点（ピン）ツール | 糸の結び目・回転軸 |
| 糸（自動 or 手動） | 上のパーツと下のパーツをつなぐ鉛直の糸 |

ポイントは、**素材ごとの密度から重さと重心を計算し、実際に吊るしたときの傾きをプレビューする**こと。
2D で水平に描いても、右側では物理的に釣り合う角度まで傾く。
ドローイングの構図と、重力による「ずれ」の両方がデザイン要素になる。

> 将来オプション：「バランス補正」ボタンで、描いた構図のまま水平に釣り合うように吊り点の位置を自動提案する。

## 2. 技術スタック（案）

| 領域 | 採用候補 | 理由 |
| --- | --- | --- |
| 基盤 | Vite + TypeScript + React | 軽量・高速な開発、UI 部品が作りやすい |
| 状態管理 | Zustand + Immer（履歴パッチで Undo/Redo） | 2D と 3D で同じドキュメントを共有 |
| 2D エディター | 自前 SVG レンダリング + **paper.js** の幾何演算 | ベジェ・ヒットテスト・ブーリアン演算・オフセットが揃っている |
| 3D | **three.js**（react-three-fiber + drei） | ExtrudeGeometry、PBR マテリアル、環境光 |
| 物理 | 静的釣り合いは自前ソルバー、揺れは簡易剛体振り子（必要なら Rapier） | モビールは木構造なので解析的に解ける |
| 素材テクスチャ | ambientCG 等の CC0 PBR テクスチャ | 木・金属・石・コンクリート・石膏 |
| 保存 | JSON（ローカル / IndexedDB）、SVG 入出力 | Illustrator との往復 |

## 3. データモデル

```ts
type Doc = {
  parts: Part[];          // 図形（板・ワイヤー）
  pins: Pin[];            // 吊り点
  strings: StringLink[];  // 糸（pin → pin）
  materials: Material[];
};

type Part = {
  id: string;
  kind: 'plate' | 'wire';
  path: BezierPath;        // アンカー + ハンドル（Illustrator と同じ表現）
  materialId: string;
  thickness: number;       // 板厚 mm（plate）
  diameter?: number;       // 線径 mm（wire）
  depthOffset?: number;    // 奥行き方向の位置（任意）
};

type Material = {
  id: string; name: string;
  category: 'wood' | 'metal' | 'stone' | 'concrete' | 'plaster' | 'other';
  density: number;         // g/cm³ → 重さ計算に使用
  pbr: { baseColor; roughness; metalness; maps? };
};
```

- 2D の 1 単位 = 1 mm（実寸で設計・制作に使えるように）
- 図形同士が重なる／接するパーツは「グループ（1 つの剛体）」として扱う

## 4. 機能一覧とフェーズ

### Phase 0 — 土台（〜数日）
- プロジェクト雛形、左右分割レイアウト（境界ドラッグでリサイズ）
- ドキュメントストア、Undo/Redo、JSON 保存・読み込み

### Phase 1 — 2D 図形エディター（Illustrator 相当の操作感）
- **選択ツール (V)**：移動・拡大縮小・回転、バウンディングボックス、複数選択
- **ダイレクト選択 (A)**：アンカー・ハンドルの個別編集
- **長方形ツール (M)**：Shift で正方形、Alt で中心から、角丸
- **楕円ツール (L)**：Shift で正円、Alt で中心から
- **ペンツール (P)**：クリックで直線、ドラッグでハンドル、Alt でハンドル分離、始点クリックで閉じる、アンカー追加/削除
- **曲線ツール (Shift+~)**：クリックした点を通るスムーズな曲線（Catmull-Rom → ベジェ変換）
- スナップ（グリッド・アンカー・スマートガイド）、ズーム/パン（Space ドラッグ）
- レイヤーパネル、プロパティパネル（素材・厚み・線径）
- **SVG 読み込み**：既存の Illustrator ドローイングを書き出して取り込み可能に

### Phase 2 — 3D プレビュー
- 閉じた図形 → 押し出し（ExtrudeGeometry、面取りオプション）
- 開いたパス → TubeGeometry でワイヤー化
- 糸の描画、天井の吊り元
- OrbitControls、環境マップ照明、影、背景（白い壁・ギャラリー風など）
- 2D の変更が即座に 3D に反映（差分更新でリアルタイム）

### Phase 3 — モビール物理
- 吊り点 + 糸から **木構造（ツリー）** を自動構築
- 葉から順に、各部分系の **質量と重心** を計算（面積 × 厚み × 密度）
- 各吊り点で、重心が真下に来る角度を算出 → 3D で傾けて表示
- 吊り点の重心からのずれ・傾き角を 2D 側にもガイド表示
- 揺れアニメーション：鉛直軸まわりの回転（風）＋ 小さな振り子運動、オン/オフ・強さ調整
- 不安定（重心が吊り点の真上など）や、パーツ同士の衝突を警告

### Phase 4 — 素材ライブラリ
| カテゴリ | 例 | 密度 g/cm³（目安） |
| --- | --- | --- |
| 木材 | ヒノキ / メープル / オーク / ウォールナット / バルサ | 0.15–0.75 |
| 金属 | 真鍮 / 銅 / ステンレス / アルミ / 鉄（黒皮） | 2.7–8.9 |
| 石材 | 大理石（白） / 御影石 / スレート | 2.6–2.8 |
| コンクリート | 打放し / 研ぎ出し | 2.3 |
| 石膏 | 白 / 着色 | 1.0–1.2 |
| その他 | アクリル（透明）/ 紙 | 0.7–1.2 |

- 素材ごとに PBR（色・粗さ・金属感・木目方向）、木目の向きは図形ごとに回転可
- 仕上げバリエーション（オイル・塗装・研磨・ヘアライン など）
- ユーザー定義の素材を追加可能

### Phase 5 — 書き出し・制作支援
- 3D：glTF / GLB、スクリーンショット（PNG）、回転動画
- 制作用：パーツごとの **原寸 SVG / DXF**（レーザーカット・切り出し用）、吊り点の穴位置
- パーツリスト（素材・寸法・重量・総重量）
- 共有用 URL（後回しで可）

## 5. ディレクトリ構成（案）

```
src/
  app/            レイアウト、ツールバー、パネル
  model/          Doc 型、ストア、履歴、シリアライズ
  editor2d/
    tools/        select, direct, rect, ellipse, pen, curvature, pin
    render/       SVG レンダラー、ガイド、ハンドル
    geometry/     ベジェ演算（paper.js ラッパー）
  preview3d/
    build/        Part → Mesh 変換（extrude / tube）
    materials/    素材定義・テクスチャ読み込み
    scene/        ライト、カメラ、環境
  physics/        ツリー構築、重心・釣り合い計算、揺れシミュレーション
  io/             JSON / SVG / glTF / DXF 入出力
```

## 7. 決めておきたいこと（オーナー確認）

1. **2D と立体の対応**：上記の「正面図＝モビール」モデルで良いか。
   それとも、各パーツを自由に配置し、吊り構造は別の階層ビューで組む方式が良いか。
2. **線の扱い**：ドローイングの「線」は、ワイヤー（構造材）になるべきか、板の上の装飾（彫り・描画）になるべきか。
3. **奥行き**：パーツは全て同一平面（Calder 的な平面モビール）で十分か、奥行き方向の配置や腕の回転も必要か。
4. **Illustrator との連携**：既存作品を SVG で読み込めることの優先度。
5. **用途**：鑑賞用のプレビュー中心か、実制作（寸法・重量・カットデータ）まで見据えるか。
6. **公開**：個人ツールとしてローカルで使うか、Web で公開・共有するか。
